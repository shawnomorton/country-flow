Sync from a Google Sheet

  1. In your inventory Sheet, open File › Share › Publish to web.
  2. Pick just the inventory tab and "Comma-separated values (.csv)", then Publish.
  3. Paste the link below. It is saved in this browser only, never in the app's code.

Columns are matched by name: marker, fluor, species, clone, vendor, catalog number, lot, location, expires, status, notes. Only marker and fluor are required. Anyone with the published link can read that one tab, so publish only the inventory tab.
